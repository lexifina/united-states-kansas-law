# K.S.A. 59-1712. Accounting on death or disability.
Whenever a sole or the last surviving fiduciary dies, or is adjudged an incapacitated person, the fiduciary's personal representative, upon appointment, shall file an account and application for the settlement and allowance thereof and, if proper, for distribution. If the estate has not been fully administered, the surety shall not be discharged until a successor has been appointed and qualified and receipted for the unadministered property.
