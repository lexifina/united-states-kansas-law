# K.S.A. 76-1201. Topeka state hospital and Osawatomie state hospital.
The institutions heretofore known as the state insane asylums shall be designated as the state hospitals, that at Topeka being known as the Topeka state hospital, and that at Osawatomie as the Osawatomie state hospital; and all references in this code to state insane asylums shall be construed to apply to state hospitals.
