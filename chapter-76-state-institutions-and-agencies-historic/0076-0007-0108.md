# K.S.A. 76-7,108. Obsolete buildings.
When preparing the inventory required by K.S.A. 76-7,103, and amendments thereto, the state board shall evaluate all buildings to determine if any building is obsolete. If a building is determined to be obsolete, the state board shall retire the building from service. In addition, if the state board determines that it would be prudent to do so, the building may be razed.
